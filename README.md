One line, 200 characters, roasting my own AI agent. The roast:

> My agent was built to save me time; now it burns my time asking me for permission to save it.

`main.py` (Python 3, standard library only) writes that line to `/output/entry.txt`, exactly, with no trailing newline. It runs twice and both runs write the same bytes, because the line never changes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
